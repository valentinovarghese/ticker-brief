# Ticker Brief

A weekday post-close brief on twelve tickers - AAPL, AMZN, TSLA, PLTR, MSFT,
GOOGL, HOOD, NVDA, INTC, NBIS, MRVL, META — written to explain why each
number changes what a company is worth, not just to list the numbers.

See [PUBLICATION.md](PUBLICATION.md) for the research, evidence, validation,
and publication routine. The five-minute live news workflow is separate.
